Self-Hosted Infrastructure & Identity Lab

Proxmox Windows Server 2025 Active Directory DNS

Problem
Build a realistic enterprise-style environment to practice systems administration and identity management.
Approach
Deployed Proxmox VE as the hypervisor, provisioned Windows Server 2025 as a domain controller, and configured Active Directory Domain Services, DNS, OUs, users, groups, and domain authentication.
Tools
Proxmox VE · Windows Server 2025 · Active Directory · Windows DNS · LXC
Result
A working domain environment with role-based group membership and reliable domain join and authentication for client systems.
What I Learned
Practical AD design decisions, DNS behavior inside a domain, and the operational trade-offs of RBAC in a lab-scale environment.

Containerized Services with Nginx Proxy Manager & SSL

Docker Docker Compose Nginx Proxy Manager SSL/TLS

Problem
Host multiple internal services safely behind a single entry point with trusted certificates.
Approach
Deployed containerized services using Docker and Docker Compose, then placed Nginx Proxy Manager in front to handle routing, SSL/TLS termination, and certificate lifecycle.
Tools
Docker · Docker Compose · Nginx Proxy Manager · Linux
Result
Internal services reachable via clean hostnames with valid SSL certificates and centralized reverse-proxy configuration.
What I Learned
How reverse proxies simplify certificate management, and why consolidating ingress improves both operability and security posture.

Phishing Email Analyser (Browser-Based)

HTML CSS JavaScript Phishing Triage

Problem
Make phishing indicators easier to understand and triage without sending email content to any third party.
Approach
Built a local, browser-based tool that scans pasted email content against explainable rules (urgency language, credential requests, suspicious links, spoofing clues) and produces a risk score plus a downloadable local report.
Tools
HTML · CSS · Vanilla JavaScript
Result
A static, privacy-first tool that runs entirely in the browser with no backend, no trackers, and no external API calls.
What I Learned
How to translate phishing-awareness concepts into explainable detection rules, and how to design a tool that prioritizes privacy and clarity over flashy automation.
